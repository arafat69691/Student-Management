# Student Management System

A simple **Django web application** to manage student information.  
This project demonstrates basic **CRUD operations** (Create, Read, Update, Delete) with a database and a web interface.

---

## 📂 Features

- Add new students
- View all students
- Edit student information
- Delete students
- Simple and easy-to-use interface

---

## ⚙️ Tech Stack

- Python 3.x
- Django 4.x
- SQLite (default Django database)
- HTML (templates)
